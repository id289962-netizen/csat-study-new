# 2028 수능 학습 사이트 묶음

## 구성
- `index.html`: 하루별 수능 학습 계획 (기숙사 필수 면학 시간 반영)
- `vocabulary.html`: 수능 핵심 어휘 트레이너
- `manifest.webmanifest`, `sw.js`, `icon.svg`: 홈 화면 설치 및 오프라인 캐시 지원

## 고정 웹 주소 만들기 (GitHub Pages 예시)
1. GitHub 계정으로 새 저장소(repository)를 만듭니다. 예: `csat-study`
2. 이 ZIP의 압축을 풀고 **파일 220개(index.html, vocabulary.html, manifest.webmanifest, sw.js, icon.svg)** 를 저장소 최상위(root)에 업로드합니다.
3. 저장소의 **Settings → Pages** 로 이동합니다.
4. Build and deployment에서 **Deploy from a branch** 를 선택하고, Branch는 `main`, Folder는 `/ (root)` 로 설정한 뒤 Save를 누릅니다.
5. 게시가 완료되면 `https://계정이름.github.io/csat-study/` 형태의 주소가 생깁니다.
6. 해당 주소로 접속하면 학습 계획 사이트가 열리고, 상단 링크로 어휘 사이트를 오갈 수 있습니다.

※ 공개 주소는 GitHub 계정에서 저장소를 게시한 뒤에만 확정됩니다. 이 패키지에는 사용자의 GitHub 계정 접근 권한이 없으므로 대신 게시하거나 실제 주소를 만들어 낼 수는 없습니다. 비밀번호나 인증 코드는 채팅에 보내지 마세요.

## 태블릿에서 오프라인으로 사용하기
1. 위 고정 HTTPS 주소를 Chrome 또는 삼성 인터넷으로 한 번 접속합니다.
2. 두 페이지를 각각 한 번 열어 캐시가 저장되도록 합니다.
3. 브라우저 메뉴에서 **홈 화면에 추가 / 앱 설치**를 선택합니다. (브라우저와 기기에 따라 문구가 다를 수 있습니다.)
4. 이후 인터넷이 끊겨도 설치한 사이트에서 두 페이지를 열 수 있습니다. 첫 접속 및 캐시 저장 전에 오프라인 이용은 불가능합니다.

## 학습 기록 저장
학습 체크와 어휘 진도는 브라우저의 로컬 저장 공간(localStorage)에 저장됩니다. 동일한 브라우저·사이트 주소에서 사용하세요. 브라우저 데이터 삭제, 시크릿 모드, 다른 브라우저/기기로 변경하면 기록이 공유되지 않을 수 있으므로 주기적으로 기록을 백업하는 것이 안전합니다.

## 참고
- HTML 파일을 단순 다운로드해 `file://`로 열면 사이트는 동작하지만, 브라우저 보안 제한 때문에 서비스 워커 기반 자동 오프라인 캐시 및 설치 기능은 작동하지 않습니다. 고정 HTTPS 주소에서 최초 설치를 완료한 뒤 오프라인 기능을 사용하세요.


[최신 버전 안내]
- 두 사이트는 주간 캘린더형 디자인과 공통 색상으로 통일했습니다.
- 학습 계획 사이트에서 ET·EP1·EP2 중 공부하지 못한 시간만 선택하면 주간 여유 시간에 자동 재배분합니다.
- 사유 입력은 필요하지 않습니다.
- 재배분은 금요일 여유 시간 250분, 토요일 40분, 일요일 15분을 순서대로 사용하며, 초과분은 다음 주로 이월합니다.
